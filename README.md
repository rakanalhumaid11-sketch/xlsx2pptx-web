# تقرير صيانة المغذي

موقع بسيط يحوّل ملف إكسل الملاحظات إلى تقرير بوربوينت جاهز.

## الاستخدام

ارفع ملف الإكسل فقط، واكتب رقم إشعار الفحص إن توفر (اختياري)، ثم اضغط
«توليد التقرير». لا يوجد اختيار قالب ولا ربط أعمدة ولا تحديد عدد شرائح.

## ماذا يفعل

يُقرأ من الإكسل تلقائيًا: اسم المغذي ورقم المحطة (يُبنى منهما رمز مثل
`M13-8903`)، وعدد الملاحظات، وأنواعها وعدد تكرار كل نوع، وبيانات كل ملاحظة
(رقمها، وصفها، المكتب، الإحداثيات، صورتها).

الشرائح الناتجة:

| الشريحة | المحتوى |
|---|---|
| الغلاف | اسم المغذي وتاريخ اليوم |
| الملخص | إجمالي الملاحظات، عدد أنواعها، الملاحظات المعالجة، وجدول بعدد تكرار كل ملاحظة |
| شريحة لكل ملاحظة | صورة «قبل»، ورقم الملاحظة، والوصف، والمكتب، والإحداثيات (مع رابط خرائط) |
| الشكر | ثابتة |

جدول الملخص يتسع لـ 21 نوعًا في الشريحة الواحدة؛ إذا زادت الأنواع تُفتح
شريحة ملخص إضافية بعنوان «(تابع)» تلقائيًا.

خانة «صورة بعد» تبقى فارغة دائمًا في كل الشرائح.

## الصور

ملفات الإكسل المصدَّرة من النظام تحتوي نسخة من كل صورة بداخلها، فيقرأها
الموقع مباشرة من الملف بدل تنزيلها من الإنترنت — لذلك يكتمل التقرير خلال
ثوانٍ. وإن لم تكن الصور مضمَّنة، تُنزَّل من روابطها تلقائيًا (أبطأ).

## الملفات

- `app.py` — الموقع (Flask): الرفع، المتابعة، التحميل.
- `builder.py` — قراءة الإكسل وبناء التقرير.
- `engine.py` — أدوات التعامل مع بوربوينت (نسخ شرائح، إدراج صور، روابط).
- `template.pptx` — القالب الثابت. كل شكل فيه يحمل اسمًا يبدأ بـ `PH_`.
- `build_template.py` — يُعيد بناء القالب من تقرير سابق (يُشغَّل عند تغيير التصميم فقط).

## التشغيل محليًا

```bash
pip install -r requirements.txt
python app.py
```

ثم افتح <http://localhost:5000>.
